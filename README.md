# TansiEdits

Tansi Cyril video editor portfolio.

## Current live architecture
- `index.html` reads published projects, published testimonials and site content from Supabase.
- `admin/index.html` handles admin login.
- `admin/dashboard.html` manages projects, testimonials and site content.
- `public-portfolio-policies.sql` contains the public read policies needed by the live portfolio.

## Deployment
Deploy the repository through Vercel as before. No TikTok/API integration is required for this version.
